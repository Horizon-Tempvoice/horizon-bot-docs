## Key concepts

### Generator Channel
These specialized voice channels automatically generate a temporary channel when joined. You can set up multiple Generator Channels by repeating the configuration steps; each one can be customized independently to define how its temporary channels behave.

<Callout title="Notice" type="warn">
    You can have a maximum of 3 Generator Channels <strong>(Not user channels, they can be as much as you want)</strong> per server. Deleting a Generator will also delete the record in the database of the Bot.
</Callout>

### Tempvoice Panel
The Tempvoice Panel, <em>referred as the <strong className="text-fd-primary">Horizon-Panel</strong></em>, is a Discord native interface that allows you to manage your temporary voice channels as a alternative to the Slash Commands.

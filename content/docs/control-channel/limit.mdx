---
title: Channel User Limit
description: Set how many users can join your temporary channel.
icon: Users
---

<DiscordCommandInput command="limit" option="limit" description="The maximum number of users (0 = unlimited, max 99)." value="4" />

In this example, the channel will change its user limit from ``unlimited`` to ``4``.

<Callout title="Note" type="idea">
    If you save the channel to a [session](/session), the saved user limit replaces the default user limit from the [Dashboard](https://dashboard.horizon-bot.me) whenever that session is loaded.
</Callout>

<Callout title="Channel Moderators" type="info">
    Channel moderators can also use this command. Server admins can disable this in the dashboard.
</Callout>

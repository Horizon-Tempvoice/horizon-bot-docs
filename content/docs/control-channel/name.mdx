---
title: Channel Name
description: Rename your temporary channel.
icon: PencilLine
---

<DiscordCommandInput command="rename" option="name" description="The new name for your channel (1-100 characters)." value="Your awesome name" />

In this example, the channel will change its name from ``Fabi's Channel`` to ``Your awesome name``

<Callout title="Note" type="idea">
    If you save the channel to a [session](/session), the saved name replaces the default name from the [Dashboard](https://dashboard.horizon-bot.me) whenever that session is loaded.
</Callout>

<Callout title="Channel Moderators" type="info">
    Channel moderators can use this command if explicitly enabled by the server admin in the dashboard.
</Callout>

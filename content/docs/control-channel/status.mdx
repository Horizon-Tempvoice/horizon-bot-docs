---
title: Set Status
description: Set a short status message on your temporary channel.
icon: MessageSquare
---


Use `/status action:Set` to add a status text to your channel that is visible to all members in the channel list. A form opens where you enter the text (max. 500 characters). Use `/status action:Remove` to clear it.

<Callout title="Channel Moderators" type="info">
    Channel moderators can use this command if explicitly enabled by the server admin in the dashboard.
</Callout>

<Callout title="Vote required" type="info">
    This command needs a [vote](/other-commands#vote) for Horizon within the last 12 hours. Servers with Extended Access don't need this.
</Callout>

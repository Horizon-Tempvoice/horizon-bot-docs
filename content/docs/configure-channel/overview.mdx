Everything a server admin can change lives in the [Dashboard](https://dashboard.horizon-bot.me). Log in with Discord and pick a server. You only see servers where you have the **Manage Server** permission.

<ImageWithCaption src="/img/content/the_dashboard_main.png" alt="The Horizon Dashboard" maxWidth="600px" />

A server page lists your Creator Channels. Pick one to configure how its temporary channels behave. Every Creator Channel is configured separately, so you can have a strict one and a relaxed one side by side.

<Callout title="Note" type="info">
    Changes are only sent once you press **Save Changes** in the bar at the bottom. They apply to channels created from then on, not to channels that already exist.
</Callout>

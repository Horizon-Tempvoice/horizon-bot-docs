These settings apply to the whole server, not to a single generator.

<Callout title="Where to find this?" type="info">
    Open the [Dashboard](https://dashboard.horizon-bot.me), pick your server and open **Settings**.
</Callout>

## Bot Language

Sets the language Horizon answers in on your server. Available are English, German, Spanish and Russian.

This is separate from the dashboard's own language, which you change with the flag at the top of the page.

## Profiles

What a saved profile stores, how many slots each member gets, and whether autosave is on by default. Each generator then decides what it restores. See [Saved Profiles](/configure-channel/generator/saved_profiles).

## Blocks

How [blocks](/control-channel/block) behave when a blocked member leaves the server and comes back. Both options are off by default.

| Setting | What it does |
|---|---|
| **Re-apply blocks on rejoin** | When a blocked member rejoins the server, Horizon blocks them again in every temporary channel that still exists. |
| **Log possible block bypasses** | When a member rejoins the server within 15 minutes of being blocked, Horizon posts a **Possible Block Bypass** entry to the [moderation log](/configure-channel/generator/logging#moderation-log) of that channel's generator. |

With logging on, you can pick a **Role to notify**. That role is pinged with every possible block bypass, and nobody else is.

<Callout title="Not proof of intent" type="info">
    Leaving and rejoining shortly after a block isn't necessarily an attempt to get around it. The entry is a hint that looking into it is recommended, not a verdict.
</Callout>

<Callout title="Note" type="warn">
    Entries are only posted if the generator has a moderation log set up. For the ping to work, the role has to be mentionable, or Horizon needs the **Mention @everyone, @here and All Roles** permission. The dashboard warns you if Horizon might not be able to ping the role you picked.
</Callout>

## Admin commands

Some of this is also available directly in Discord. These commands are limited to admins by default, and you can change who may use them in your server's integration settings.

| Command | Description |
|---|---|
| `/setup` | Create a generator, optionally with a panel channel. See [Quickstart](/quickstart). |
| `/panel send [channel]` | Post the panel into a text channel. |
| `/cleanup` | Remove leftover records of channels that no longer exist on Discord. |

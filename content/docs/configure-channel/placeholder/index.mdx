---
title: Placeholders
description: Channel names are personalized using placeholders, which get replaced with real user data when a channel is created.
icon: Braces
---

The ``{ }`` button next to a name field in the dashboard inserts a placeholder; it lists all of them with a short description.

| Placeholder | Inserts | Example |
| --- | --- | --- |
| [`{OWNER_NICK}`](/configure-channel/placeholder/OWNER_NICK) | Server display name of the owner (default in the name template) | ``🎙・Fabi`` |
| [`{OWNER_USERNAME}`](/configure-channel/placeholder/OWNER_USERNAME) | Discord account username of the owner | ``🎙・john_doe`` |
| [`{OWNER_ID}`](/configure-channel/placeholder/OWNER_ID) | Discord user ID of the owner | ``🎙・123456789012345678`` |
| [`{CUSTOM}`](/configure-channel/placeholder/CUSTOM) | The name the owner set with `/name` | ``🎮・ranked grind`` |
| [`{NUMBER}`](/configure-channel/placeholder/NUMBER) | Lowest free number among the generator's open channels | ``🔊・Gaming 2`` |
| [`{RANDOM_WORD}`](/configure-channel/placeholder/RANDOM_WORD) | A random word from a list you define | ``⚔️・Mage`` |

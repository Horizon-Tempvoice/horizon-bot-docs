---
title: Placeholders
description: Channel names are personalized using placeholders, which get replaced with real user data when a channel is created.
icon: Braces
---

The ``{ }`` button next to a name field in the dashboard inserts a placeholder; it lists all of them with a short description.

| Placeholder | Inserts | Example |
| --- | --- | --- |
| [`{OWNER_NICK}`](#owner_nick) | Server display name of the owner (default in the name template) | ``🎙・Fabi`` |
| [`{OWNER_USERNAME}`](#owner_username) | Discord account username of the owner | ``🎙・john_doe`` |
| [`{OWNER_ID}`](#owner_id) | Discord user ID of the owner | ``🎙・123456789012345678`` |
| [`{CUSTOM}`](#custom) | The name the owner set with `/name` | ``🎮・ranked grind`` |
| [`{NUMBER}`](#number) | Lowest free number among the generator's open channels | ``🔊・Gaming 2`` |
| [`{RANDOM_WORD}`](#random_word) | A random word from a list you define | ``⚔️・Mage`` |

## `{OWNER_NICK}`

`{OWNER_NICK}` is replaced by the channel owner's display name on the server. If they have a server nickname set, that is used. Otherwise it falls back to their account username.

A template like `` 🎙・{OWNER_NICK} `` would produce channels such as:

- ``🎙・Fabi``
- ``🎙・ProGamer``
- ``🎙・john_doe``

This is also the default placeholder used in the channel name template.

## `{OWNER_USERNAME}`

`{OWNER_USERNAME}` is replaced by the Discord account username of the person who created the channel. This is the unique handle tied to their account, not their server-specific display name.

A template like `` 🎙・{OWNER_USERNAME} `` would produce channels such as:

- ``🎙・john_doe``
- ``🎙・gamer123``
- ``🎙・fabi``

## `{OWNER_ID}`

`{OWNER_ID}` is replaced by the Discord user ID of the channel owner. This is a unique numeric identifier assigned to every Discord account.

A template like `` 🎙・{OWNER_ID} `` would produce channels such as:

- ``🎙・123456789012345678``

## `{CUSTOM}`

When a user renames their channel with `/name`, that name is stored and inserted wherever `{CUSTOM}` appears in the template. Everything around it stays fixed, so server admins can enforce a consistent format while still giving users control over part of the name.

For example, with the template `` 🎮・{CUSTOM} ``:

- A user who set their name to ``ranked grind`` gets ``🎮・ranked grind``
- A user who set their name to ``chill session`` gets ``🎮・chill session``

The ``🎮・`` part cannot be changed by the user, only the custom portion.

<Callout title="No name set yet?" type="info">
    If a user has not set a name yet, ``{CUSTOM}`` falls back to a configurable default. Out of the box this is ``{OWNER_USERNAME}``, but it can be changed. Other placeholders are supported inside the fallback field.
</Callout>

<Callout title="Change the fallback" type="idea">
    The field **`{CUSTOM}` Custom Name Fallback** sits right below the name template in the [Channel name](/configure-channel/generator/channel_name) section.
</Callout>

## `{NUMBER}`

Each new channel gets the lowest number that none of the generator's open channels is using yet. With the template `` 🔊・Gaming {NUMBER} ``, three channels in a row give:

- ``🔊・Gaming 1``
- ``🔊・Gaming 2``
- ``🔊・Gaming 3``

If ``Gaming 2`` is deleted, the next new channel becomes ``Gaming 2`` again.

A channel keeps its number for its whole life. Renaming it with `/name` (when the template also contains [`{CUSTOM}`](#custom)) or handing it to a new owner doesn't change it.

<Callout title="Made for unmanaged generators" type="idea">
    [Unmanaged](/configure-channel/generator/owner_tools#managed-or-unmanaged) channels have no owner, so owner placeholders don't fit them. `{NUMBER}` gives public lobbies a clean name like ``🔊・Gaming 1``, ``🔊・Gaming 2``.
</Callout>

<Callout title="No renumbering" type="info">
    Open channels are never renumbered. If ``Gaming 2`` is deleted while ``Gaming 1`` and ``Gaming 3`` are still open, they stay as they are, and the gap is only filled by the next new channel.
</Callout>

<Callout title="Good to know" type="warn">
    Channels that were already open before you added `{NUMBER}` to the template don't get a number. A channel renamed to a completely different name keeps its number in the background but no longer shows it.
</Callout>

## `{RANDOM_WORD}`

Each time a channel is created, `{RANDOM_WORD}` picks one word at random from a list you define and inserts it into the channel name.

With the words ``Warrior``, ``Mage``, and ``Rogue`` configured, a template like `` ⚔️・{RANDOM_WORD} `` could produce:

- ``⚔️・Warrior``
- ``⚔️・Mage``
- ``⚔️・Rogue``

<Callout title="Customize the word list" type="idea">
    The field **`{RANDOM_WORD}` Word List** sits right below the name template in the [Channel name](/configure-channel/generator/channel_name) section. Up to 50 words.
</Callout>

---
title: Channel Name
description: The name template for new temporary channels, the {CUSTOM} fallback and the word list.
---

<Callout title="Where to find this?" type="info">
    Open the [Dashboard](https://dashboard.horizon-bot.me), pick your server, open **Generators** and choose the generator. This is the **Channel name** section of its page.
</Callout>

| Setting | Description |
|---|---|
| **Name Template** | The name new channels get, up to 100 characters. The ``{ }`` button next to the field inserts a [placeholder](/configure-channel/placeholder) like `{OWNER_NICK}`. |
| **`{CUSTOM}` Custom Name Fallback** | Used instead of `{CUSTOM}` while the owner hasn't picked a name yet. See [`{CUSTOM}`](/configure-channel/placeholder/CUSTOM). |
| **`{RANDOM_WORD}` Word List** | The pool for `{RANDOM_WORD}`, up to 50 words. Type a word and press Enter or **Add**. See [`{RANDOM_WORD}`](/configure-channel/placeholder/RANDOM_WORD). |

The fallback and the word list only appear once the template contains `{CUSTOM}` or `{RANDOM_WORD}`. Removing the placeholder hides the field but keeps what you entered.

Owners can rename their channel with [`/name`](/control-channel/name) if **Rename** is enabled in [Owner Tools](/configure-channel/generator/owner_tools).
